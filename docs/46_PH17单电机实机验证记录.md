# PH17 单电机实机验证记录

日期：2026-11-08。用户确认新接入 PH17 为裸电机，授权速度 ±1 rad/s 各约 1 秒，以及位置正转 90°、反转 90°回起点。已使用仓库 `ros2_canopen` 独立 `Cia402Driver` 完成四段运动，最终停止失能。

## 设备与运行方式

- CAN 卡 `gs_usb`，`can0`，1 Mbit/s，发送队列 1000；只读扫描发现 Node-ID **1**。
- 固件 `V140-0264`；设备类型 `0x00220811`；厂商 1640，产品 `0x00221701`，修订 16，序列号 `0x00360031`。
- 真实 `6502=0x03CD`，正常报告模式能力；本次关闭零能力掩码兼容选项。
- 按设备 `6091:01/02=6619136` 及项目历史比例，使用 6619136 count/圈，未套用摆臂外部三倍传动比例。角度未用外部量具校准。
- ROS2 Humble，domain 73，单节点 `/ph17_motor`；50 Hz SYNC/轮询，反馈期限 100 ms，关闭启动回零，保留运动安全检查。
- 使用 `/tmp/ph14-motor-check-install` 已有构建产物，包含记录 45 的驱动修复及工作区未提交修改；本次未修改驱动源码或重新运行软件回归。
- 首次 DCF 生成因 EDS 相对路径失败，对应启动未成功；改从配置目录生成并启动后 boot 正常。该准备失败未执行运动。

## 实测结果

速度通过 `cyclic_velocity_mode`（CSV 9）及 `target` 服务下发。各段从零速开始，持续发送目标约 1 秒，主动发送零速后 halt/disable；下一段显式重新初始化。中段速度取运动开始后 0.3–0.85 秒反馈样本。

| 测试 | 结果 |
| --- | --- |
| +1 rad/s | 中段速度中位数 **+0.999644 rad/s**，范围 +0.996944 至 +1.003708；包含减速等待的位移 **+53.924814°** |
| −1 rad/s | 中段速度中位数 **−1.000178 rad/s**，范围 −1.005131 至 −0.995639；包含减速等待的位移 **−59.601537°** |
| 正转 90° | CSP 8，3 秒渐变目标、保持 0.5 秒；反馈位移 **+89.999946°** |
| 反转 90° | CSP 8，3 秒渐变目标、保持 0.5 秒；反馈位移 **−90.000109°** |
| 停止 | halt/disable 成功，状态字 **0x0250**，实际速度 **0**，故障码 **0** |

位置使用 `cyclic_position_mode`，不是 Profile Position 1；命令为绝对位置的逐步插补，未直接跳变 90°。两段位置相互往返，速度两段受加减速和时间差影响，不保证速度测试净位移为零。以上是编码器反馈结果，不代替外部角度或调速精度标定。

## 恢复与边界

主站已退出；按测试前备份恢复心跳、插补周期、模式及全部 PDO，90 次 PDO 恢复写入均应答成功。完整备份集合读回比较仅 `6064` 实际位置和 `606C` 实际速度变化；零偏、软限位及其余对象一致。初始失能态速度读回为 62 count/s，最终为零；初始位置 −1383094 count，最终 −1487457 count。没有写入保存或出厂复位对象。

CAN 最终 error-warning、error-passive、bus-off 及收发错误计数均为 **0**。本次没有采集完整 CAN 帧抓包；证据为原参数备份、ROS 服务结果、50 Hz 反馈样本、节点日志、恢复应答和最终读回。没有验证停发命令、进程失效自动停止、200 Hz 或整车 ros2_control，不据此更新整车验收状态。

证据：[20261108-ph17-single-axis](evidence/20261108-ph17-single-axis/)。复用脚本仅适用于本次单轴配置与已确认裸电机，执行前须重新确认现场设备及参数。

## 同日位置抖动诊断与改善

用户反馈 PH17、PH14 在位置模式抖动明显。首轮“位置到达”只证明编码器终点，不代表运动平稳性通过。本轮仅连接 PH17 Node-ID 1，未复测 PH14。

### 发现与修改

首轮测试脚本每次 target 都创建 ROS 客户端，等待服务响应后再额外 spin 20 ms；实际 target 应答间隔中位数约 **40 ms**，最大 **124 ms**，与 **20 ms** 驱动/SYNC 周期不匹配。此前 CSP 匀速段反馈速度大幅波动。

新增 [test_canopen_csp.py](../tools/test_canopen_csp.py)：复用客户端，以单调时钟的绝对截止时间调度，将服务耗时计入本周期；错过周期时跳过旧时刻，不补发密集历史目标。保留反馈新鲜度、行程和目标误差检查、100 ms target 应答期限及最终 halt/disable。默认使用五次曲线 `10u³−15u⁴+6u⁵`，使端点速度与加速度为零；另提供 linear 用于隔离定时修改的效果。本次未调整电机增益、滤波参数或驱动源码，保持 50 Hz。

这是有人值守的 standalone 测试程序，不是生产控制器或命令看门狗；进程失效停止未验证。调用前须启动匹配设备/比例的单轴主站，`--period` 应与驱动和 SYNC 配置一致。本次实际命令为：

```bash
python3 tools/test_canopen_csp.py --execution stream --device ph17_motor --degrees 90 --duration 3 --period .02 --profile linear --output /tmp/ph17-csp-check/linear-50hz.json
python3 tools/test_canopen_csp.py --execution stream --device ph17_motor --degrees 90 --duration 3 --period .02 --profile quintic --output /tmp/ph17-csp-check/quintic-50hz.json
```

需先加载 ROS2 Humble 及本次驱动安装环境，并使用主站相同 ROS domain。不要直接对未确认的机构执行上述裸电机行程。

### 实机对比

使用相同 ±90°、每段 3 秒线性轨迹对比，均按每段约 0.4–2.6 秒的反馈样本统计；首轮起点时间取该段首个反馈样本，存在约一个反馈周期的对齐误差。速度来自 50 Hz 编码器反馈，不能作为高频机械振动测量。

| 项目 | 首轮脚本 | 修正定时后 |
| --- | --- | --- |
| 正向匀速段速度标准差 | 0.207860 rad/s | **0.006285 rad/s** |
| 反向匀速段速度标准差 | 0.243796 rad/s | **0.006182 rad/s** |
| 正向匀速段速度范围 | 0.071964～1.372431 rad/s | **0.523805～0.555901 rad/s** |
| 反向匀速段速度范围 | −1.671147～−0.069354 rad/s | **−0.555249～−0.522500 rad/s** |
| target 应答间隔中位数 | 约 40 ms | **约 20 ms** |
| target 应答最大间隔 | 约 124 ms | **约 22.24 ms** |

本轮 CAN 抓包证实两个线性运动中段各有 110 个 RPDO1 目标帧，没有相邻重复位置目标；SYNC 中位周期约 20.03 ms，最大约 22.78 ms。与反馈及用户现场“明显减轻”的确认一致，支持测试目标下发时序是本次 PH17 抖动的主要因素；不排除设备参数或其他运行路径还存在影响。

修正定时的线性往返实测 **+89.999565° / −89.999184°**。随后默认五次曲线往返实测 **+90.000054° / −90.000326°**，相对原始两端目标误差分别约 **+0.000163° / −0.000163°**。五次曲线中段速度随轨迹变化，不拿其速度标准差与匀速轨迹作比较。

两轮均完成停止失能、零速、无故障。最终主站退出，恢复原心跳、插补周期、模式及 PDO；本轮前后备份比较仅实际位置 `6064` 变化，零点、限位及其余对象相同。最终状态字 0x0250、故障 0、速度 0，CAN 错误计数均为零。完成脚本语法检查及上述两轮实机验证，未重跑完整驱动软件回归。

对比反馈、CAN 抓包、脚本快照、恢复记录见 [抖动改善证据](evidence/20261108-ph17-csp-timing/)。PH14 需要使用同一方法接入后复测；本轮不登记 PH14 位置模式或整车控制已修复。

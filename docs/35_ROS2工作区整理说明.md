# ROS2 工作区整理说明

日期：2026-10-26。项目确认只维护 ROS2 Humble，不再要求回退 ROS1。本文说明当前目录及本次检查结果。

## 参考代码

历史代码集中到 [reference/ros1](../reference/ros1/README.md)：

- 四组纯 ROS1 代码：Eyou_Canopen_Master、Eyou_ROS1_Master、tcp_bridge、vision_opencv。
- 已迁移包中的旧 XML launch、旧控制源码、旧配置和原说明。
- can_driver 中未参与 ROS2 构建的 RobotHW、XmlRpc 解析器、旧 rostest、ROS1 控制器 YAML 和 Noetic CI。
- 原 docs/归档 的 ROS1 历史方案与报告；ROS2 第一阶段分组合同记录 30 保留在当前 docs。

参考根包含 COLCON_IGNORE/CATKIN_IGNORE。旧 CANopen 子模块的父仓库 gitlink、.gitmodules 声明、本地配置与工作树 .git 指针已解除，源码变为普通文件。保留的 Git 历史对象不构成活动链接。

活动 ROS2 子模块仍为 can_driver、ros2_canopen、realsense-ros、OrbbecSDK_ROS2、aruco_ros、easy_handeye2 共 6 个。驱动子模块中的本地修复及此次整理变更仍须随匹配版本一起提交。

## 活动目录与文档

原 ros1_bridge 目录改为 host_bridge，原 Eye_in_hand 改为 eye_in_hand，与现有 ROS2 包名一致。launch、src、scripts、config 使用常规目录，CMake、构建和测试入口同步更新。根 Catkin CMakeLists.txt 符号链接已移除，其原目标记录在参考目录。

根 README、包 README、docs 索引、系统拓扑/架构/数据流、计划 25/26、现场操作与验收说明均按当前实现更新。整车默认分组策略与底层空 group_policy 的全局诊断模式已分别说明。ROS1 回退要求删除，设备参数恢复和 ROS2 匹配版本恢复要求继续保留。

根 CI 改为 Humble 核心构建与回归，使用系统 Lely；依赖脚本补齐 ros-humble-lely-core-libraries 并支持 root 容器。GitHub 远端 CI 尚未在本次本地整理中执行，私有子模块仍需相应凭证。

## 删除与保留

已删除源码树中的 docs/evidence、docs/artifacts 及原归档 evidence/artifacts、log、占位 install、tmp、TF 导出 frames.gv/frames.pdf、car_urdf/export.log 和 Python 缓存。旧测试源码随其 ROS1 实现移入参考目录；活动回归源码和采集工具继续保留。

.deps/librealsense 是运行所需 SDK；robot_canopen_config 的 legacy 映射/EDS/DCF 是当前生成和校验输入；host_bridge 的本地视频 YAML 是部署配置，均予以保留。参考目录的旧 .gitignore 改为 gitignore.ros1，防止 EDS、总线配置和旧文档被隐式忽略。

新增输出继续写源码树外的 /tmp 前缀，.gitignore 增补日志、evidence 和临时产物规则。源码整理后的验证不会重新留下工作区 logs/evidence。

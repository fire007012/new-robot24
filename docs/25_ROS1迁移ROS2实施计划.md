更新：2026-11-08。活动工作区统一使用 Ubuntu 22.04 / ROS2 Humble，不再构建 Catkin 包。ROS1 源码和文档保存在 [reference/ros1](../reference/ros1/README.md)，由 `COLCON_IGNORE` 隔离。

本页保留迁移范围与交付顺序；匹配版本、验证结果和可勾选事项统一维护在 [清单 36](36_ROS2迁移剩余事项清单.md)，避免多份进度重复更新。

## 交付顺序

1. **当前版本软件回归已完成。** 2026-11-08 full 通过，源码差异、版本、指纹及日志已归档，依赖 gitlink、验证入口和文档纳入本批次提交。后续代码有变更时重跑受影响验证。
2. **登记设备与关联条件。** 建立现场 commissioning 副本，备份原持久化参数，落实可信姿态/制动、支撑及载荷输入；未经核验保持 `commissioned: false`。
3. **完成 CAN 与整车验收。** 按 [28](28_CANopen软件交付与实机验收.md) 的 M0–M4/P6 执行单轴、停止/制动、跨后端轨迹、分组恢复与性能测试，填写 [F01–F13 模板](32_分组隔离现场验收记录模板.md)；同时复核轮距、夹爪行程和 KDL 精度。
4. **完成真实感知与外围。** 核验序列号、USB/固件、图像/深度/CameraInfo、marker 和标定精度；提供 YOLO 权重，验证完整 RTSP、CO₂、热成像、上位机及整车负载。
5. **固定交付版本并部署。** 保存匹配提交/标签、依赖和参数清单、安装产物校验值及持久证据；验证目标机搬迁和 ROS2 软件/设备参数恢复。安全行为有变更时重做受影响验收。

## 依赖与资料维护

平台采用 MoveIt 2 OMPL + KDL 和 Gazebo Fortress 6。六个活动子模块的当前版本见 [清单 36](36_ROS2迁移剩余事项清单.md)，获取与发布见 [子模块工作流](git_submodule_workflow.md)。只有两个 CAN 子仓库自主维护，其他优先使用上游原版，项目适配放在项目包中。

`.deps/librealsense` 是当前 SDK；`robot_canopen_config/config/legacy_*` 是活动配置生成/校验输入，均需保留。测试源码持续维护，构建、日志、截图和现场原始证据写到源码树外。旧 marker `6x6_250 / 582` 超出字典范围，不直接沿用；相机安装姿态与标定外参各只有一个权威发布者。

构建和启动见 [根 README](../README.md)，架构见 [01](01_系统概述与硬件拓扑.md)、[03](03_架构设计与决策过程.md)、[06](06_项目架构图与数据流向图.md)。

每次停止试验记录：故障施加时刻、软件检出时刻、许可撤销时刻、停止命令时刻、各轴物理停止时刻、制动/载荷结果及测量不确定度。单独记录失联轴不能提供反馈时采用的外部测量依据。

被动采集命令（在独立终端于试验前启动，输出目录每次唯一）：

```bash
ros2 run robot_hardware capture_acceptance --interfaces canable0 canable1 \
  --seconds 120 --bitrate 1000000 --output /实际路径/acceptance/F01-run01
```

该采集工具记录 CAN 与 ROS 证据；外部停止/制动测量另附。断开通信后的反馈不可读必须如实记录。

## 4. 匹配 ROS2 版本发布与恢复

全部必需项实机通过且现场确认后，先保存两个子模块的匹配提交，再更新主仓库 gitlink，记录三个提交、发布标签和安装清单。发布产物须由这组匹配源码构建并通过离线回归，现场配置与验收记录一并归档；若验收后修改安全行为，重新执行受影响项。

回退前 halt/shutdown，确认设备实际停止和新主站退出，再启动原版本；设备参数按原基线恢复并读回。完成记录并确认后才能勾选计划 29 的 P6。

本文“原版本/回退”仅指已验证的 ROS2 匹配版本和设备参数恢复，不包含 ROS1 基线。

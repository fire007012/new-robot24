# PP 单电机实机验证记录

日期：2026-11-08。使用真实 CAN 卡和裸 PP 电机，验证 ROS2 `can_driver` standalone 单轴路径。该记录不代表整车 ros2_control、分组安全或 CANopen 验收通过。

## 设备与构建

- 主仓库：`92608d3879b42e96ff3d7f1ee2a13347d1730d0f`；`can_driver`：`b240b38c06670b577b83251b15d31e32b44b2d18`。
- CAN 卡：USB `1d50:606f`，`gs_usb`，接口 `can0`，1 Mbit/s。初始 DOWN，由现场用户启用。
- PP 读取序列号探测得到节点 `0x17`，序列号 `0x0830004F`。用户确认是裸电机；整车配置中相同节点属于夹爪，不能直接套用夹爪的米制换算。
- 单轴使用 `position_scale: 65536`、`velocity_scale: 65536`、正方向 1、CSP；保持原设备限位、零点和 EEPROM。
- ROS2 Humble；独立编译 `robot_safety` 和 `can_driver` 成功，产物在 `/tmp/pp-motor-check-install`。使用 ROS domain 71、命名空间 `/pp_test`，仅注册一个电机。

## 实测

原始读回：位置 −6320 count、速度 0、模式寄存器 `0x0F = 3`（速度模式）、未使能；限位使能 `0x38 = 1`，上限 `0x39 = -5461`，下限 `0x3A = -27306`，偏置 `0x3B = 0`。按本次角度比例，限位约为 −150° 至 −30°。

通过 ROS2 服务初始化并选 CSP，先预置当前位置；使能后必须显式 resume，enable 会将状态置为 Armed。确认真实反馈的使能、模式及有效标志后，以 3 秒渐变位置目标转 −10°，保持 1 秒，随后 halt、disable、shutdown。

| 项目 | 结果 |
| --- | --- |
| 起点 | −6321 count，−0.606018285 rad |
| 目标位移 | −10° |
| 终点 | −8142 count，−0.780604473 rad |
| 反馈位移 | −10.003051758° |
| 目标误差 | −0.003051758° |
| 停止后反馈 | 速度 0，未使能，无故障，反馈新鲜 |

上述角度根据 65536 count/圈计算，未用外部量具校准。首次测试在 enable 后未再次 resume，保持 Armed，反馈位移为 0；补齐生命周期调用后上述运动通过，没有修改驱动源码。

## 保留限位的位置与速度模式测试

用户随后改为保留设备限位，要求位置模式约 120°、速度 1 rad/s，并验证速度模式。实际使用两个独立配置顺序启动同一节点，前一个节点退出后才启动后一个，没有并行运行电机主站。

standalone 节点原来没有读取每轴 `pp_position_default_velocity` / `pp_csp_default_velocity`，无法直接使用配置指定位置模式速度。本次补齐两项读取、合法性校验与向 PP 后端传递。重新编译通过；负数、NaN、溢出和不足原始单位分辨率的速度配置均被拒绝。源码差异保存在证据目录的 `can-driver.patch`。本次未运行完整软件回归。

| 模式 | 命令与实测 |
| --- | --- |
| 位置 | 先从 −8141 count 移至下限附近 −27304 count，再向上限 −5461 count 发送目标；最终 −5463 count，反馈位移 **119.976196°** |
| 位置速度配置 | `pp_position_default_velocity: 1.0`，抓包确认 `0x09` 写入 10430，折算 **0.999964 rad/s**；位置反馈峰值约 1.012 rad/s |
| 速度 | 发送 **−1 rad/s** 约 0.7 秒后主动发零速；反馈位移 −41.231689°，运行中采样速度有波动，部分中段样本中位数约 −1.047 rad/s，瞬时最大幅值约 **1.239 rad/s** |
| 最终只读检查 | 位置 −12956 count，实际速度 0、目标速度 0、模式为原速度模式、未使能、故障寄存器 0 |
| 原参数复核 | `0x38=1`、`0x39=-5461`、`0x3A=-27306`、`0x3B=0`，与原限位和零偏一致；抓包没有限位、零偏和保存寄存器的写入 |

速度测试主动发送了零速并停止，**没有验证停发命令后的自动停止**。反馈速度短时波动需要后续测量，不作为调速精度通过。先前 180° 要求已由用户替换，未修改限位来执行 180°。

## 通信异常与验收边界

运动完成不代表 CAN 稳定性通过。接口 `txqueuelen` 为 10，位置与速度测试启动日志均出现 `ENOBUFS` / TX queue saturated，说明有发送帧因回压丢弃。最终内核累计计数为 error-warning **1205**、error-passive **2992**、bus-off **111**；初始为零，最终接口状态为 ERROR-ACTIVE。仅凭该记录不能确定队列拥塞与总线错误的因果关系。

尝试将队列扩大至 1000 因本机 sudo 需要密码未执行，当前队列仍为 10。连续运行前需要现场检查终端电阻、接线、供电及 CAN 卡/固件，并调整接口队列后重新采集错误计数和速度响应。不能将此次运动成功登记为整车或稳定性验收通过。

原始参数、单轴配置、测试脚本、反馈样本、CAN 抓包、日志和最终参数复核保存在 [证据目录](evidence/20261108-pp-single-axis/)。测试脚本仅适用于本次节点、原始限位和已确认的裸电机，不是通用整车启动入口。全部测试结束后驱动节点已退出。未执行 F01–F13，不变更其完成状态。

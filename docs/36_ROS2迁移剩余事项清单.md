```bash
bash tools/validate_ros2.sh /tmp/robot24-offline-20261104 full
```

手动启动 Mock：

```bash
source /tmp/robot24-offline-20261104-install/setup.bash
ros2 launch robot_bringup full_system_mock.launch.py
# 需要键盘界面和 Servo 时，在上述命令追加 enable_servo:=true ui:=keyboard
```

另一个终端 source 同一环境后，显式建立 Mock 会话：

```bash
source /tmp/robot24-offline-20261104-install/setup.bash
ros2 service call /robot_runtime/init std_srvs/srv/Trigger '{}'
for condition in arm_secured support_trusted payload_retained; do
  ros2 service call "/mock/conditions/$condition" std_srvs/srv/SetBool '{data: true}'
done
ros2 service call /robot_runtime/enable std_srvs/srv/Trigger '{}'
ros2 service call /robot_runtime/resume std_srvs/srv/Trigger '{}'
```

上述条件仅为 Mock 输入。真实设备基线和自动采样配置继续保持 `commissioned: false`；依赖 vcan 的用例在接口缺失时跳过，不计总线验证。YOLO 权重尚未提供，本机无 MediaMTX 可执行文件，视频检查覆盖 H265 编解码与空源管理，不包含完整 RTSP 发布/拉流。通用 `easy_handeye2` 运动辅助节点的服务测试使用模拟运动对象；整车自动采样采用 `eye_in_hand/auto_sample.py` 的项目 Action 路径，不启用 MoveIt 直接执行。

本批次失败证据保留在源码树外：`*-moveit-before-fix.log`（配置未完成）、`*-relocation-before-fix.log`（并行 spawner 重复加载）、`*-session-race-failure.log`（准备状态竞态）、`*-status-timeout.log`（启动只读查询超时）、`*-readiness-timeout.log`（就绪查询丢失回复）、`*-canopen-test-shutdown-failure.log`（测试线程退出竞态），统一前缀为 `/tmp/robot24-offline-20261104`。
